# فروشگاه لباس اسپریت — Landing Page

سایت استاتیک و سبک برای GitHub Pages، با طراحی RTL و بافت کاغذی روشن، مناسب معرفی فروشگاه لباس مردانه سایز بزرگ.

## قبل از انتشار
در فایل‌های `index.html`، `robots.txt` و `sitemap.xml` مقدار `YOUR-GITHUB-USERNAME` را با نام کاربری GitHub خودتان عوض کنید و اگر نام repository متفاوت است، مسیر آن را هم تغییر دهید.

## ساختار
- `index.html` — صفحه اصلی + SEO + JSON-LD
- `styles.css` — طراحی واکنش‌گرا
- `script.js` — تاریخ/ساعت شمسی، منوی موبایل، سایز‌یاب، نظرات نمونه و خواندن `etela.xml`
- `etela.xml` — اطلاعیه قابل ویرایش
- `robots.txt` و `sitemap.xml` — فایل‌های پایه سئو
- `manifest.webmanifest` و `assets/favicon.svg` — PWA/Favicon
- `assets/` — لوگو و تصاویر نمونه

## انتشار روی GitHub Pages
1. فایل‌ها را در repository قرار دهید.
2. از Settings → Pages، منبع انتشار را روی branch اصلی و پوشه `/root` بگذارید.
3. آدرس نهایی سایت را در canonical، Open Graph و schema جایگزین کنید.

## نکته مهم درباره محتوا
متن نظرات مشتریان برای چیدمان اولیه به‌صورت نمونه نوشته شده و بهتر است پس از جمع‌آوری رضایت‌های واقعی با نام مشتریان واقعی جایگزین شود.


### اطلاعیه فروشگاه
فایل `etela.xml` را ویرایش کنید. اگر هیچ `<notice>` فعالی وجود نداشته باشد، نوار اطلاعیه اصلاً در سایت نمایش داده نمی‌شود.
